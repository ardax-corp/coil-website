Returns the 64-byte SHA-512 digest of `data`.

## Parameters

| Name | Type |
|------|------|
| `data` | `Vec<byte>` |

## Returns

`Result<Vec<byte>, CryptoError>`

## Examples

```coil
use crypto::{sha512};
use string::{to_bytes};
use tests::assert;
let digest = sha512(to_bytes("abc")).unwrap_or(Vec::new());
assert!(digest.len() == 64);
```
