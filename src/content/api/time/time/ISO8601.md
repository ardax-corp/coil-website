[`format`](/packages/time/reference/time/format) / [`parse`](/packages/time/reference/time/parse) pattern for an ISO 8601 date-time body, `YYYY-MM-DDTHH:MM:SS`.

It has no fraction and no zone. Use [`format_rfc3339`](/packages/time/reference/time/format_rfc3339) / [`format_iso8601`](/packages/time/reference/time/format_iso8601) for
output with a `Z` suffix, and [`parse_rfc3339`](/packages/time/reference/time/parse_rfc3339) / [`parse_iso8601`](/packages/time/reference/time/parse_iso8601) to read
fractions and offsets.

## Examples

```coil
use time::{parse, format_rfc3339, ISO8601};
use tests::assert;
let ts = match parse("2024-03-01T12:30:00", ISO8601) {
    Result::Ok(t) => t,
    Result::Err(_) => panic "parse",
};
assert!((format_rfc3339(ts).ok() ?? "") == "2024-03-01T12:30:00Z");
```
