Generates a time-based (version 1) UUID.

The UUID holds the current time in 100 ns ticks since 1582-10-15, a
14-bit clock sequence and a 48-bit node. The node is 6 random bytes with
the multicast bit set (never the host MAC); the node and clock sequence are
drawn once per process and shared with [`v6`](/packages/uuid/reference/uuid/v6). Prefer [`v7`](/packages/uuid/reference/uuid/v7) for new
time-ordered IDs: v1 does not sort by time as bytes or text.

## Returns

`Result<Uuid, UuidError>`

## Errors

Returns [`UuidError::Entropy`](/packages/uuid/reference/uuid/UuidError#variant-entropy) when the random source fails (first call
only) and [`UuidError::Time`](/packages/uuid/reference/uuid/UuidError#variant-time) when the clock fails.

## Examples

```coil
use uuid::{v1};
use tests::assert;
let id = match v1() {
    Result::Ok(u) => u,
    Result::Err(_) => panic "v1 failed",
};
assert!(id.version() == 1 && id.variant() == 2);
```
