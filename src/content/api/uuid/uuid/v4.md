Generates a random (version 4) UUID.

122 of the 128 bits come from [`crypto::random_bytes`](/packages/crypto/reference/crypto/random_bytes), the OS CSPRNG; the
rest are the version and variant bits.

## Returns

`Result<Uuid, UuidError>`

## Errors

Returns [`UuidError::Entropy`](/packages/uuid/reference/uuid/UuidError#variant-entropy) when the random source fails.

## Examples

```coil
use uuid::{v4};
use tests::assert;
let id = match v4() {
    Result::Ok(u) => u,
    Result::Err(_) => panic "v4 failed",
};
assert!(id.version() == 4 && id.variant() == 2);
assert!(id.to_string().len() == 36);
```
