Generates a random (version 4) UUID.

122 of the 128 bits come from [`entropy::bytes`](/docs/reference/entropy/bytes), the OS CSPRNG; the rest
are the version and variant bits.

## Returns

`Result<Uuid, UuidError>`

## Errors

Never returns an error today; the [`Result`](/docs/reference/prelude/Result) keeps the signature in line
with the time-based generators. A failing OS random source panics.

## Examples

```coil
use uuid::{v4};
use tests::assert;
let id = match v4() {
    Result::Ok(u) => u,
    Result::Err(_) => panic "v4 failed",
};
assert!(id.version() == 4 && id.variant() == 2);
assert!(id.to_string().len() == 36);
```
