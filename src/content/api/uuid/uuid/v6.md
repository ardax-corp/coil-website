Generates a reordered time-based (version 6) UUID.

The same fields as [`v1`](/packages/uuid/reference/uuid/v1), with the timestamp stored most significant bits
first so that IDs sort by creation time. Shares the clock sequence and node
with [`v1`](/packages/uuid/reference/uuid/v1).

## Returns

`Result<Uuid, UuidError>`

## Errors

Returns [`UuidError::Time`](/packages/uuid/reference/uuid/UuidError#variant-time) when the clock fails.

## Examples

```coil
use uuid::{v6};
use tests::assert;
let id = match v6() {
    Result::Ok(u) => u,
    Result::Err(_) => panic "v6 failed",
};
assert!(id.version() == 6 && id.variant() == 2);
```
